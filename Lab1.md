## Підготовка до лабораторної

### Glosssary of Basic English Terms (Virtual Environments)

**Virtual Machine** — a software-based emulation of a physical computer that runs an operating system and applications.

**Virtualization** — a technology that allows multiple operating systems to run on a single physical machine.

**Hypervisor** — software or firmware that creates and manages virtual machines.

**Type 1 Hypervisor** — a hypervisor that runs directly on the physical hardware without a host operating system.

**Type 2 Hypervisor** — a hypervisor that runs on top of a host operating system.

**Host Operating System** — the main operating system installed on the physical machine.

**Guest Operating System** — an operating system installed and running inside a virtual machine.

**Kernel** — the core component of an operating system that manages hardware resources.

## Типи гіпервізорів

Гіпервізор дозволяє одночасно запускати кілька ОС та розподіляти ресурси.

- **Тип 1** — використовується на серверах, висока продуктивність  
- **Тип 2** — зручний для навчання та тестування

---

## Огляд VirtualBox (варіант 16)

VirtualBox — гіпервізор другого типу.  
Дозволяє створювати віртуальні комп’ютери з різними ОС.

Основні компоненти:
- хост-ОС  
- віртуальні машини  
- віртуальне обладнання

Основні можливості:
- запуск кількох ВМ  
- встановлення різних ОС  
- розподіл ресурсів  
- збереження стану ВМ

## Відповіді на запитання

### Етапи розгортання операційної системи у VirtualBox

Для встановлення операційної системи у середовищі VirtualBox спочатку потрібно встановити сам гіпервізор на комп’ютер. Після цього створюється нова віртуальна машина, де обирається тип та версія операційної системи. Далі налаштовуються основні параметри — обсяг оперативної пам’яті та розмір віртуального жорсткого диска. На завершальному етапі підключається ISO-образ операційної системи та виконується її встановлення.

---

### Апаратні обмеження при встановленні 32- та 64-бітних ОС

Під час встановлення 32-бітної операційної системи існує обмеження на використання оперативної пам’яті — зазвичай не більше 4 ГБ. Для встановлення 64-бітної системи необхідний процесор із підтримкою 64-бітної архітектури та апаратної віртуалізації. Якщо така підтримка відсутня, встановлення або коректна робота 64-бітної ОС буде неможливою.

---

### Основні етапи встановлення Linux у текстовому режимі

Під час встановлення Linux у текстовому режимі спочатку обирається мова інтерфейсу та налаштовується розкладка клавіатури. Далі виконується розмітка диска та вибір основних системних пакетів. Після цього створюється обліковий запис користувача, проводяться базові налаштування системи та завершується інсталяція операційної системи.

---

### Встановлення GNOME та KDE після текстового режиму

Якщо Linux вже встановлена у текстовому режимі, графічне середовище можна додатково встановити за допомогою менеджера пакетів.

Для встановлення GNOME використовується команда:

sudo apt install ubuntu-gnome-desktop

Для встановлення KDE використовується команда:

sudo apt install kde-standard

---

### Графічні інтерфейси в дистрибутивах Linux (Варіант 16)

KDE — сучасне та функціональне графічне середовище з широкими можливостями налаштування. Часто використовується як повноцінне робоче середовище в багатьох дистрибутивах Linux.

Fluxbox — легке та мінімалістичне графічне середовище, яке споживає мінімум системних ресурсів. Підходить для комп’ютерів із невисокими технічними характеристиками або для користувачів, які надають перевагу простоті.

## Контрольні запитання

### 1. Порівняння гіпервізорів типу 1 та типу 2

Гіпервізори типу 1 працюють безпосередньо з апаратним забезпеченням комп’ютера без використання базової операційної системи. Вони забезпечують вищу продуктивність і стабільність та застосовуються переважно у серверних і корпоративних середовищах.

Гіпервізори типу 2 встановлюються поверх існуючої операційної системи та використовують її ресурси. Зазвичай вони застосовуються на персональних комп’ютерах для навчання, тестування або одночасного використання кількох операційних систем.

---

### 2. Поняття GNU GPL та його основна ідея

GNU GPL — це ліцензія вільного програмного забезпечення, яка гарантує користувачам право використовувати, змінювати та поширювати програму. Основна ідея цієї ліцензії полягає в тому, що всі модифікації програмного коду повинні залишатися відкритими та доступними для інших користувачів.

---

### 3. Суть програмного забезпечення з відкритим кодом

Програмне забезпечення з відкритим кодом надає вільний доступ до вихідного коду програми. Це дозволяє користувачам аналізувати її роботу, вносити зміни відповідно до власних потреб та вдосконалювати її. Такий підхід сприяє прозорості, безпеці та швидкому розвитку програмних продуктів.

---

### 4. Що таке дистрибутив

Дистрибутив — це готовий програмний комплекс на базі ядра Linux, який включає саме ядро, системні утиліти, бібліотеки та, зазвичай, графічне середовище. Дистрибутиви спрощують процес встановлення та використання операційної системи Linux.

---

### 5. Задачі системного адміністрування в Linux

За допомогою Linux можна виконувати адміністрування серверів, керувати користувачами та їх правами доступу, налаштовувати мережу, здійснювати резервне копіювання даних, контролювати використання системних ресурсів та автоматизовувати завдання за допомогою скриптів.

---

### 6. Зв’язок між Android та Linux
Операційна система Android базується на ядрі Linux. Ядро Linux відповідає за керування пам’яттю, процесами та апаратними ресурсами, тоді як інші компоненти Android адаптовані для мобільних пристроїв.

---

### 7. Embedded Linux: можливості та сфера використання

Embedded Linux використовується у вбудованих системах, таких як маршрутизатори, телевізори, промислове обладнання та інші спеціалізовані пристрої. Він забезпечує стабільну роботу, гнучке налаштування та адаптацію до конкретних апаратних вимог.

---

### 8. Зміна режиму завантаження Linux та різниця між CLI і GUI

Режим завантаження Linux можна змінювати між текстовим режимом (runlevel 3) та графічним режимом (runlevel 5) шляхом налаштування параметрів запуску системи.

CLI — це режим керування через введення команд у терміналі.  
GUI — це режим із графічним інтерфейсом, вікнами та меню.

CLI забезпечує більшу гнучкість і точність керування, тоді як GUI є більш зручним для повсякденного використання.
